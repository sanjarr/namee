# DentalImplantReel — моушен-ролик «Имплантация зуба»

Remotion + TypeScript, 1080 × 1920 (9:16), 30 fps, 1800 кадров (60 с). Стиль и динамика взяты
из референса (tech-motion: тёмный фон, жёлтые плашки, HUD, таймер-обратный отсчёт),
цвета, шрифт и логотип — из брендбука «32 КАРАТА».

```bash
npm install
npm run studio   # npx remotion studio
npm run render   # npx remotion render DentalImplantReel out/dental-implant-reel.mp4 --codec=h264 --crf=18
```

Две композиции:

| ID | Что это |
|---|---|
| `DentalImplantReel` | основная: tech-motion по референсу, 60 с, с музыкой и звуками |
| `DentalImplantReelClassic` | первая версия по ТЗ v2: светлая, с «проводником»-имплантатом, 36 с |

## Фирменный стиль «32 КАРАТА»
Sapphire `#04254E` (фон), Immature yellow `#DEFF5C` (акцент референса: плашки, подсветка слов,
зачёркивания, таймер), Indigo Crayola `#5D80D8`, White. Шрифт — Ubuntu (Google Fonts);
HUD-микротекст набран Ubuntu Mono из того же семейства. Белый логотип стоит только на финальной
карточке (`public/brand/`, вырезан из страницы «Версии логотипа» брендбука).

## Как устроена основная композиция
- `src/dynamic/theme.ts` — таймлайн сцен (`DS`, `dat(сцена, кадр)`) и палитра. Длительности кратны
  биту (120 BPM → 15 кадров), поэтому монтаж ложится на музыку.
- `src/dynamic/ui.tsx` — языковые элементы референса: `Slab` (жёлтая плашка), `Hl` (подсветка слова
  «маркером»), `Strike` (неоновое зачёркивание), `Typed` (печатная машинка), `Mask` (выезд строки).
- `src/dynamic/Hud.tsx` — постоянный слой: таймер-кольцо 01:00 → 00:00, ник, уголки, тайм-код, прогресс.
- `src/dynamic/scenes/D1…D8` — сцены: хук → сомнение → последствия → цифра → решение → было/стало →
  преимущества → запись.
- `src/dynamic/sfx.ts` — таблица «кадр → звук → громкость».

## Звук
Всё синтезируется кодом, лицензия не нужна:
- `python3 scripts/make-music.py` → `public/music.mp3` (электронный грув 120 BPM в Fm; ритм, пауза
  перед «25%», приглушение на «было» и раскрытие на «стало», финальный хвост). Нужны numpy, scipy, ffmpeg.
- `python3 scripts/make-sfx.py` → `public/sfx/*.mp3` (удары, клики, нарастания, щелчки клавиш и т. д.).

Свою музыку можно положить в `public/music.mp3` поверх сгенерированной.

Тексты и ник (`clinicName`, `handle`, `keyword`) — в `dynamicDefaultProps` (`src/dynamic/DynamicReel.tsx`).

## Классическая версия (`DentalImplantReelClassic`)

### Тайминг
Длительности сцен заданы в одном месте — `SCENES` в `src/theme.ts`. Сегменты проводника
(`src/guide/legs.ts`) и звуки (`src/sfx.ts`) привязаны к началу сцен через `at(сцена, кадр)`,
поэтому паузы на чтение можно менять, не пересчитывая кадры вручную.

### Устройство
- `src/guide/legs.ts` — таблица сегментов проводника G0–G20 (раздел 5.3 ТЗ).
- `src/guide/state.ts` — позиция, наклон, парение и видимость имплантата как чистые функции кадра.
- `src/guide/GlowPath.tsx` — трёхслойная линия (ореол / средний / ядро), режимы `fly` и `draw`.
- `src/scenes/S1…S7` — сцены, кадры внутри сцены локальные.

### Отличия от ТЗ
- **Ролик удлинён с 24 до 36 с**: добавлены паузы на чтение (~3 слова в секунду), сами
  анимации не замедлены. Body 42 → 52 px, пункты сцены 3 — 54 px, лейблы 26 → 34 px,
  H2 88 → 92 px, кнопка 36 → 40 px.
- **Орбита G16** — 2,5 оборота вместо одного: так она заканчивается в нижней точке
  (540, 796), с которой начинается G17, и проводник не «телепортируется».
- Во время пульса кнопки контур G18 масштабируется вместе с кнопкой, чтобы совпадать с ней.
- Заголовки автоматически ужимаются, если не помещаются в безопасную зону.
- Шрифт Erbaum и золотая палитра из ТЗ заменены на фирменные (Ubuntu, Sapphire/Indigo);
  на коронке в сцене 5 появились грани бриллианта, как в знаке клиники.
- Строка «это мелочь.» поднята на 0.1em, чтобы зачёркивание на y = 900 шло по центру строчных букв.
